
# Requisition and Spend Analysis | Power BI

## Project Overview

This project focuses on analysing organisational requisitions and expenditure using Microsoft Power BI. It transforms requisition data into meaningful insights to support expenditure monitoring, procurement visibility and data-driven decision-making.

The dashboard provides an overview of requisition activity, spending patterns, departmental expenditure and requisition values.

## Objectives

- Analyse requisition volumes and expenditure.
- Monitor spending across departments.
- Identify high-value requisitions.
- Understand expenditure patterns and trends.
- Present actionable insights through interactive visualisations.

## Tools and Technologies

- **Microsoft Power BI** – Data visualisation and dashboard development.
- **Power Query** – Data cleaning and transformation.
- **DAX** – Measures and analytical calculations.
- **Microsoft Excel** – Data source and preparation (where applicable).

## Key Areas of Analysis

- Total requisition value.
- Number of requisitions.
- Departmental expenditure.
- Highest-value requisitions.
- Requisition status analysis.
- Spending distribution and trends.

1. Clone or download this repository.
2. Open the `.pbix` file using Microsoft Power BI Desktop.
3. If required, update the data source paths.
4. Refresh the data to explore the report.
